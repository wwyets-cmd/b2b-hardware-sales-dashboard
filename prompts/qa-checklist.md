# 看板 QA 清单（交付前逐项核对）

交付前逐项检查，每项给出"通过/不通过 + 证据"。任何一项不过，修复后重跑全部。

---

## 一、数据三处交叉验证（最重要）

同一数字在三个位置必须一致（口径差异除外）：

1. KPI 卡片总销售额 = 月度趋势各月之和 = 客户/品牌/品类合计；
2. 若存在口径差异（如分层/气泡剔除 <1000 元、品类饼剔非商品品类），**必须在角标写明**；
3. 用明细/JSON 复算关键数：总销售额、总成本、毛利、客户数、SKU 数、订单数。

- [ ] 总销售额、毛利、2026/当年销售额与聚合脚本输出一致；
- [ ] 品类饼总额、产品分析总额、品牌饼总额对得上（差异 <0.1% 且有说明）。

---

## 二、筛选联动（每个筛选器都要测）

逐一切换并重算：

- [ ] 年度切换：目标块、KPI、图表全部跟随年份；
- [ ] 月度 Tab：选单月时月数、盈亏线、所有统计按选中月算；
- [ ] 品牌筛选：客户排名、客户明细、气泡、KPI 全部按品牌过滤；
- [ ] 品类筛选：同上；
- [ ] 业务员筛选：金额、客户数、明细按业务员；
- [ ] 客户搜索：只看该客户；
- [ ] 纳入调货开关：开启/关闭后调货数据显隐、合计正确（默认关闭）。

---

## 三、同比口径

- [ ] 同比用对日裁剪（今年各月日期段，去年取相同日段）；
- [ ] 去年为 0 / 无可比期显示"—"，不是 0%；
- [ ] 2025 这类无 2024 数据的年份不报错；
- [ ] 全部年份连续趋势不受年份选择器控制，但受其他筛选影响。

---

## 四、客户分层

- [ ] 六分层户数与金额相加 = 纳入分层的总量；
- [ ] 金额线 5/3/1 万、频次线 5 月、边界规则（>5 归维护、=1 归稳定）正确；
- [ ] 0 元客户不会被误判为"重要价值"（除非有明确其他维度并标注）；
- [ ] 角标写明覆盖率。

---

## 五、产品 / SKU

- [ ] 品牌数/品类数/SKU 数正确且带同比；
- [ ] 动销率 = 有销售天数 ÷ 期间总天数；高/低周转（≥20%/≤5%）正确；
- [ ] SKU 气泡纵轴切换正常，>40%/ <0% 凸显；
- [ ] 明细表含动销率列（百分比）；
- [ ] 品类矩阵盈亏线随固定费用/月数/销售额变化。

---

## 六、交互与下钻

- [ ] 框选：入口可发现（默认激活或"框选"文字），选中后统计面板完整；
- [ ] 框选统计：客户数/总金额/平均金额/总利润/平均毛利/业务排名/明细均正确；

- [ ] 饼图点击：品牌→品类联动，产品明细（金额/毛利/动销）正确；
- [ ] 客户点/行 → 客户弹窗；所有按钮均有真实 handler（无僵尸按钮）。

- [ ] 图表重渲染 dispose，无实例泄漏；
