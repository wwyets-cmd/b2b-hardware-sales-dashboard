# 03 · 指标字典（每个数字的判断依据）

本文件列出看板每个指标的**定义、公式、口径、单位**。当用户追问"这个数怎么来的/判断依据
是什么"，以本文件为准。所有金额公式默认在"元"上计算，展示再换算为万元。

---

## 一、主页 KPI（全局销售看板）

### 总销售额
- 定义：选中期间所有出库明细的**折后金额**合计（净销售）。
- 公式：`Σ sales`（剔退货后；含/不含调货由开关决定）。
- 单位：万元（÷10000，2 位小数）。

### 同比增减额
- 定义：今年（选中期）相对去年同期的金额差。
- 公式：`今年销售额 − 去年同期销售额（对日裁剪后）`。
- 正数为增、负数为减。

### 同比增长率
- 定义：同比增减额占去年同期的比例。
- 公式：`(今年 − 去年) ÷ 去年 × 100%`。
- 去年为 0 或无可比月份时显示"—"。

### 年度任务达成率
- 定义：当年实际销售额占年度目标金额的比例。
- 公式：`当年实际（截至最新月）÷ 年度目标金额 × 100%`。
- 目标金额由用户单独提供，不来自明细；分子跟随年份与筛选。

### 订单笔数（业务板块）
- 定义：选中期间**不重复的单据编号数量**（同一单据编号 = 一个订单）。
- 公式：`nunique(单据编号)`。
- 注意：不是商品行数；同一单据里多个商品只算 1 笔。

### 活跃客户数
- 定义：当月有正向出库（销售额 > 1000 元）的去重客户。
- 公式：`count(distinct 客户 where 当月 sales > 1000)`，剔散客/内部。
- 期间口径按所选月汇总（月内有任意月 >1000 即计）。

### 新增客户数
- 定义：首次出库月落在统计期内（且非期初月）的客户数。
- 公式：`count(客户 where 首次出库月 ∈ 选中期)`。
- 显示依据：标注"按首次出库日期"，并区分有效/高质量/一次性。

---

## 二、成本与盈利

### 成本
- 公式：`Σ cost`（成本金额）。
### 毛利额
- 公式：`Σ(sales − cost)`。
### 毛利率
- 公式：`Σ(sales − cost) ÷ Σ sales × 100%`（**销售额加权**，非逐月平均）。
### 客户/品牌/品类利润
- 公式：`Σ sales − Σ cost`，按对应维度汇总。

---

## 三、客户新客质量

| 指标 | 公式 / 判定依据 |
| --- | --- |
| 新客户 | 首次出库月 ∈ 选中期（非期初月） |
| 有效新客 | 首次拿货后**连续销售月份 > 3 个月** |
| 高质量新客 | 存在**连续 3 个月累计 ≥ 1 万元** |
| 一次性新客 | 只买 1 个月（连续 ≤ 3），不计有效新客 |

---

## 四、沉睡 / 激活 / 流失 / 骤降

| 指标 | 判定依据 |
| --- | --- |
| 沉睡客户 | 最新日期前滚 6 个月累计 < 1000 元，且更早有采购 |
| 沉睡激活 | 沉睡客户后续单月出库 > 1000 元 |
| 流失客户 | 最新月前连续 3 个月无采购、去年同期 3 个月有销售；流失金额=去年同期 |
| 大客户骤降 | 去年同期 ≥ 5 万、今年仍拿货 < 去年 90%（降幅≥10%） |
| 中小骤降 | 去年同期 1–5 万、今年仍拿货 < 去年 80%（降幅≥30%） |

---

## 五、产品 / SKU 指标

### 品牌数 / 品类数 / SKU 数
- 定义：选中期间有销售的去重品牌 / 品类 / SKU 数量。
- SKU 已按商品编号归一（合并改名）。

### 动销率（按天）
- 公式：`有销售的天数 ÷ 选中期间总天数`。
- 高周转：动销率 ≥ 20%；低周转：动销率 ≤ 5%。

### SKU 气泡
- 横轴 = 规模（销售额，log）；纵轴 = 毛利率 或 动销率（可切换）；
- 凸显：毛利率 > 40%（高利润）或毛利率 < 0%（亏本）。

### 周转排名
- 按品类/品牌的平均动销率降序，展示 TOP N。

---

## 六、品类赚钱矩阵

- 规模轴 = 期间销售额；毛利率轴 = 加权毛利率。
- **盈亏线（毛利率）= 月度固定费用 × 月数 ÷ 期间销售额**。
- 固定费用、月数、销售额全部随筛选动态变化。

---

## 七、框选统计（客户 / SKU 气泡）

框选后对选中点（客户或 SKU）现算：

| 指标 | 公式 |
| --- | --- |
| 客户数 / SKU 数 | 选中点数 |
| 总金额 | `Σ sales` |
| 平均金额 | `总金额 ÷ 点数` |
| 总利润 / 总毛利 | `Σ(sales − cost)` |
| 平均毛利（客户） | `总利润 ÷ 总金额 × 100%` |
| 高周转 / 低周转 SKU | 框选内动销率 ≥20% / ≤5% 的数量（SKU 框选） |
| 新品数 | 首次出库月落在选中期的 SKU/客户数 |
| 去年同期 / 同比 | 对日裁剪后的去年金额与同比率 |
| 业务客户数排名 | 框选客户按业务员分组计数，降序（名字+客户数） |

## 九、指标使用红线

1. 毛利率、占比一律**加权汇总**，不做算术平均；
2. 合计、排名、占比都由明细**现算**，不用静态值；
3. 无可比期显示"—"，不写 0；
4. 同一指标跨模块必须一致，不一致先查口径再查 bug。
