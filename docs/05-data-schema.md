# 05 · 数据规范（输入与输出）

## 一、输入文件规范

- 格式：`.xls`（管家婆，xlrd 读取）或 `.xlsx`（openpyxl 读取），按月导出；
- 每个文件首个工作表为明细表；表头可能不在第 1 行（前若干行可能是标题/空行），
  需**自动定位表头**（出现"单位全名"且"折后金额"的行）；
- 每行 = 一张单据里一个商品的出库明细行；剔除"合计/总计/小计/累计"等汇总行。

### 标准列（管家婆《单位销售明细》）

单据类型、单据日期、单据编号、单位编号、单位全名、商品编号、商品全名、品牌、
职员编号、职员全名、仓库全名、销售数量、单价、金额、折扣、折后金额、含税金额、
成本金额、摘要、单据备注。

### 表头别名自动识别表

| 标准字段 | 常见别名（含其一即可，忽略空格/全半角） |
| --- | --- |
| 单据类型 | 单据类型、类型 |
| 单据日期 | 单据日期、日期、出库日期、销售日期、开单日期 |
| 单据编号 | 单据编号、单号、单据号、销售单号 |
| 客户编号 | 单位编号、客户编号、客户编码 |
| 客户名称 | 单位全名、客户名称、客户全名、单位名称、往来单位 |
| 商品编号 | 商品编号、商品编码、货号、产品编号 |
| 商品名称 | 商品全名、商品名称、品名、产品名称、货品名称 |
| 品牌 | 品牌、品牌名称、商标 |
| 职员编号 | 职员编号、业务员编号、经办人编号 |
| 职员名称 | 职员全名、业务员、经办人、销售员、客服 |
| 仓库 | 仓库全名、仓库、库房 |
| 数量 | 销售数量、数量、出库数量、销售数 |
| 单价 | 单价、售价 |
| 折后金额 | 折后金额、实际金额、含税金额、销售额、实收金额、金额 |
| 成本金额 | 成本金额、成本、成本价金额 |
| 备注 | 单据备注、备注、摘要 |

> 歧义处理：同时存在"金额"和"折后金额/含税金额"时，**销售额优先取折后金额**
> （更接近真实成交）；找不到成本列时，成本标"待补充"，不编造。

## 二、清洗与规范化

- 编号去 `.0` 尾缀，统一为字符串；
- 日期：支持 Excel 日期序列号、日期类型、文本日期，统一转 `YYYY-MM-DD`；
- 缺失品牌填"未标注品牌"，再交由分类器识别；
- SKU 按商品编号归一（合并改名）；
- 数值空值按 0；退货以负值体现（销售数量/金额）。

## 三、输出 JSON 结构（dashboard_data.json）

顶层字段及含义：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `meta` | object | 元信息（见下） |
| `monthly` | array | 每月汇总（全口径/剔调货/调货、新客/激活/活跃等） |
| `staff_month` | array | 业务员 × 月（金额/数量/成本/订单/活跃/新客/激活，含调货拆分） |
| `brand_month` | array | 品牌 × 月（销售/成本序列，含调货拆分） |
| `brand_split` | array | 品牌 × 调货标记（全期销售/数量/成本） |
| `category_month` | array | 品类 × 月（销售/成本序列） |
| `staff_brand` | array | 业务员 × 品牌 × 调货 × 月序列 |
| `staff_category` | array | 业务员 × 品类 × 调货 × 月序列 |
| `brand_category` | array | 品牌 × 品类 × 调货 × 月序列 |
| `brand_products` | object | 品牌 → TOP 商品（名/销售/数量） |
| `brand_product_month` | array | 品牌 × 产品 × 调货 × 月序列（饼图下钻） |
| `category_product_month` | array | 品类 × 产品 × 调货 × 月序列 |
| `products` | array | SKU 档案：名/品牌/品类/各月销售/成本/剔调货/销售天数/对日裁剪 |
| `customers` | array | 客户主数据（见下） |
| `cust_month` | array | 客户 × 月（id, ym, sales, qty, cost），含对日裁剪伪月 |
| `cust_prod` | object | 客户 → TOP5 商品（名/销售/数量） |
| `churn` | array | 滚动流失客户（id/名/业务员/末次/去年金额/损失） |
| `risk` | array | 骤降预警（分级、降幅、降幅率） |
| `churn_summary` | object | 流失/骤降户数与金额汇总 |

### meta 字段

`generated`（生成日期）、`date_min/date_max`、`months`（有效月序列）、`missing_note`
（缺口说明）、`rows`（总行数）、`threshold_sleep_yuan`、`initial_customers`（期初户数）、
`current_year`、`aligned_ym`（对日裁剪月）、`aligned_pseudo`（裁剪伪月）、`aligned_note`、
`partial_months`（部分月）、`non_product_categories`（非商品品类）、`role_hint`
（业务员/客服名单）。

### monthly 元素关键字段

`ym`；全口径 `sales/qty/cost/orders/cust`；剔调货 `non_*`；调货 `tra_*`；
`new_cust`（新客）、`valid_new_cust`（有效新客）、`quality_new_cust`（高质量新客）、
`activated`（沉睡激活）、`active_cust`（活跃）；对日裁剪月另含 `a_*` 系列。

### customers 元素字段

`id`、`name`、`staff`（归属业务员）、`first`（首次）、`last`（末次）、
`sales/qty/cost`（全期）、`tag`（调货标记 0/1/2）、`retail`（散客）、`internal`（内部）、
`new_ym`（新客月，期初为''）、`sleep`（当前沉睡）、`act_ever`（曾激活）、`aliases`（曾用名）。

---

## 四、单位与精度

- 输出金额：除特殊说明，序列值保留 2 位小数（单位仍是元，前端换算万元）；
- 数量、天数按实际口径；
- 比率以百分比展示（如 27.1%），内部可存小数。

---

## 五、数据缺口与空值

- 缺月、误命名、重复导出、部分月、非商品品类，在 `meta` 与页面"数据缺口"中写明；
- 无数据的字段不编造（如未导出成本、回款、库存、退货金额），在页面提示需另接对账/库存表。
